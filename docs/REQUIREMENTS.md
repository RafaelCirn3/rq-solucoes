# Requisitos

## Funcionais

1. Exibir catálogo organizado por empresa representada.
2. Cada linha do catálogo representa uma empresa e seus produtos.
3. Permitir navegação futura por produto, empresa, categoria e aplicação.
4. Permitir busca textual no catálogo.
5. Cada produto possui CTA para solicitação via WhatsApp.
6. Preparar suporte futuro a datasheets, manuais e certificados.
7. Preparar páginas amigáveis a SEO.

## Não funcionais

- Interface responsiva.
- Baixo tempo de carregamento.
- Separação entre frontend e backend.
- Deploy reproduzível via Docker.
- Configuração por variáveis de ambiente.
- PostgreSQL como banco de produção.

## Fora do escopo V0

- Carrinho.
- Pagamentos.
- Estoque.
- Login de clientes.
- Integração frontend/backend.
- Dashboard comercial.
